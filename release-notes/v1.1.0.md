# Image Converter v1.1.0

- Redesigned compact dark interface, with a 740 × 520 default window.
- Added a file picker, clearer queue, batch progress, and dark scrollbars.
- Added Extract frames: save full animation frames as numbered images in an Output subfolder.
- Added Create animation: combine still images into GIF, animated WebP, or MNG with frame ordering, timing, and looping.
- Image conversion runs in the background to keep the interface responsive.
- Protected settings during conversion, improved cancellation handling, and fixed label/input spacing.
- Retained all 32 output formats and the existing PDF and video workflows.

## Download

Download `ImageConverter-Windows-x64.zip`, extract the complete archive, and run `ImageConverter.exe`. Keep the DLLs beside the executable. No installation is required.

## Verification and limitations

Verified image conversions, PDF conversion, animation creation/extraction, frame timing/order, resizing, cancellation, and compact layouts. Video decoding still depends on Windows media support; the test clip could not be decoded on the local test machine, including with the original version's reader.
